DAY 1 – INTRODUCTION TO PROGRAMMING & PYTHON

1. Programming Basics
- Programming is the process of writing instructions for a computer.
- A set of instructions written to perform a specific task is called a program.
- Programming languages act as a bridge between humans and computers.

2. Programming Paradigms
- Procedural Programming
- Object-Oriented Programming (OOP)

3. Procedural Programming
- Focuses on functions, logic, and step-by-step execution.
- Suitable for small applications.
- Has less code reusability and is harder to maintain for large projects.

4. Object-Oriented Programming (OOP)
- Organizes code using classes and objects.
- Main concepts: Encapsulation, Inheritance, Polymorphism, and Abstraction.
- Provides better reusability, security, maintenance, and scalability.
- Suitable for large applications.

5. Python
- Python is a high-level, interpreted, general-purpose programming language.
- It focuses on simplicity, readability, and productivity.
- Features include easy syntax, dynamic typing, object-oriented support, portability, and a large library ecosystem.

6. Why Python?
- Easy to learn and write.
- Requires fewer lines of code.
- Supports faster development and easy maintenance.
- Has a large ecosystem and community support.

7. Python History
- Created by Guido van Rossum.
- Development started in 1989.
- First released in 1991.
- Python 1.0: 1994
- Python 2.0: 2000
- Python 3.0: 2008

8. Applications of Python
- Web Development
- Data Science
- Artificial Intelligence
- Automation
- Cyber Security
- Game Development
- Desktop Applications

9. Memory Allocation
- Procedural programming mainly works with variables and functions.
- OOP uses objects and attributes, with objects created in heap memory.
- OOP generally uses more memory than procedural programming.

KEY TAKEAWAY
Learned the fundamentals of programming, programming paradigms, OOP, Python features and history, applications of Python, and basic memory allocation concepts.
